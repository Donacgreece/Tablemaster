Γενικές Πληροφορίες
Αυτό το λογισμικό χρησιμοποιεί βιβλιοθήκες από πολλαπλές πηγές που υπόκεινται σε διάφορες άδειες χρήσης. Παρακάτω αναφέρονται οι άδειες που καλύπτουν κάθε εξάρτηση που χρησιμοποιείται στο λογισμικό.

1. Python Standard Library
Περιλαμβάνει τις βιβλιοθήκες: os, io, re, json, time, uuid, socket, hashlib, threading, ipaddress, subprocess, datetime
Άδεια: Python Software Foundation License
Περιγραφή: Αυτές οι βιβλιοθήκες είναι ενσωματωμένες στην Python και μπορούν να χρησιμοποιηθούν ελεύθερα χωρίς περιορισμούς.

2. SQLite
Βιβλιοθήκη: sqlite3
Άδεια: Public Domain
Περιγραφή: Η SQLite διανέμεται ως public domain. Δεν απαιτείται άδεια χρήσης.

3. Pandas
Βιβλιοθήκη: pandas
Άδεια: BSD 3-Clause License
Περιγραφή: Μπορείς να χρησιμοποιήσεις την Pandas ελεύθερα, συμπεριλαμβανομένων εμπορικών χρήσεων, υπό την προϋπόθεση ότι συμπεριλαμβάνεις αυτήν την άδεια.

4. Python-escpos
Βιβλιοθήκη: python-escpos
Άδεια: MIT License
Περιγραφή: Μια βιβλιοθήκη για εκτύπωση σε ESC/POS εκτυπωτές, βασισμένη σε Python.

5. Cryptography
Βιβλιοθήκη: cryptography
Άδεια: Apache License 2.0
Περιγραφή: Επιτρέπεται η ελεύθερη χρήση της βιβλιοθήκης, συμπεριλαμβανομένων εμπορικών εφαρμογών, υπό την προϋπόθεση ότι συμπεριλαμβάνεται η άδεια Apache 2.0.

6. Werkzeug
Βιβλιοθήκη: werkzeug
Άδεια: BSD 3-Clause License
Περιγραφή: Μπορεί να χρησιμοποιηθεί εμπορικά με την προϋπόθεση ότι παρέχεται η άδεια.

7. APScheduler
Βιβλιοθήκη: apscheduler
Άδεια: MIT License
Περιγραφή: Η βιβλιοθήκη είναι διαθέσιμη για οποιαδήποτε χρήση, συμπεριλαμβανομένων εμπορικών εφαρμογών, αρκεί να συμπεριλαμβάνεται αυτή η άδεια.

8. Flask
Βιβλιοθήκη: flask
Άδεια: BSD 3-Clause License
Περιγραφή: Μπορεί να χρησιμοποιηθεί εμπορικά με την προϋπόθεση ότι παρέχεται η άδεια.

Πνευματικά Δικαιώματα Λογισμικού
Αυτό το λογισμικό ανήκει στον Γαλατσάνο Δημήτριο και υπόκειται στις παρακάτω άδειες για τις βιβλιοθήκες που περιλαμβάνει. Σας παρακαλούμε να αναφέρετε αυτές τις άδειες αν διανείμετε ή τροποποιήσετε το λογισμικό.
